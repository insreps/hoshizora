# HOSHIZORA（ほしぞら）

小学校1〜3年生を主な対象とした、楽しく星座を学べる教育Webサービスです。  
12星座図鑑・星つなぎゲーム・クイズ・神話ストーリー・かんさつ日記を通じて、遊びながら星や星座の知識が身につきます。

## 主な機能

- **12星座ずかん**：四季・北の空の12星座をReact＋SVGで表示（ひらがな／漢字あり切替対応）
- **星つなぎミニゲーム**：星座の星を順番にタップして形を覚えるインタラクティブ体験
- **星座クイズ**：形あて・知識・神話クイズ、やさしい解説、挑戦履歴の保存
- **ミッション＆バッジ**：学習状況に応じた8つのミッション達成とバッジ収集
- **星座の物語（12話）**：七夕（織姫・彦星）やギリシャ神話の子ども向け読み物
- **かんさつ日記**：個人情報を取得せず、端末の `localStorage` に安全に保存する観察ノート
- **保護者・先生向け案内**：学習指導要領とのつながり、プライバシーポリシー、利用規約

## 技術構成

- React 19 / TypeScript / Vite / Tailwind CSS v4
- データ永続化：`StorageAdapter` 抽象化によるブラウザ内保存（将来的なクラウド同期対応設計）

## ローカル開発・テスト手順

```bash
# 依存関係のインストール
npm install

# 開発サーバー起動 (http://localhost:3000)
npm run dev

# 型チェック
npm run lint

# ユニットテスト
npx --yes tsx --test src/lib/learningEngine.test.ts

# 本番ビルド
npm run build
```

## プライバシーと安全設計

- 氏名・メールアドレス・GPS位置情報・外部広告トラッキングは取得しません。
- 学習進捗・日記データはお使いのブラウザ内（`localStorage`）のみに保存されます。
